# وِصلة — مشروع بداية لتطبيق Android

هذا المشروع يضم واجهة HTML الحالية داخل هيكل أولي قابل للتحويل إلى تطبيق Android باستخدام Capacitor.

## مهم قبل النشر
- هذه نسخة واجهة أولية. البيانات التي تحفظها الواجهة الحالية في المتصفح ليست قاعدة بيانات مشتركة بين المستخدمين.
- لم تتم إضافة نظام حسابات أو قاعدة بيانات سحابية أو بوابة دفع؛ يجب إعدادها واختبارها قبل إطلاق نسخة عامة.
- لا تضع مفاتيح سرية أو مفاتيح خدمة Supabase داخل ملفات الواجهة.

## المتطلبات
1. تثبيت Node.js (إصدار LTS).
2. تثبيت Android Studio مع Android SDK.
3. فك ضغط المشروع على كمبيوتر.

## إنشاء مشروع Android
افتح الطرفية داخل مجلد المشروع ونفّذ:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

سيفتح Android Studio مشروع التطبيق. اختبره على جهاز فعلي أو محاكي، ثم من Android Studio استخدم Build لإنتاج APK تجريبي.

## تحديث واجهة التطبيق لاحقًا
بعد تعديل `www/index.html` نفّذ:

```bash
npx cap sync android
```

ثم أعد البناء من Android Studio.

## قبل استخدامه كمنصة حقيقية
- إعداد Supabase Auth لتسجيل الحسابات.
- إنشاء جداول للطلبات والعروض والملفات الشخصية.
- إعداد سياسات Row Level Security والتحقق من صلاحيات المستخدمين.
- إضافة رفع الصور وتخزينها بأمان.
- اختبار التحقق من المدخلات، وحماية البيانات، والروابط الخارجية.
- إضافة بوابة دفع مصرية مناسبة بعد التحقق من شروط التفعيل والتسوية.

## النشر
لا تنشر نسخة إنتاجية قبل ربط قاعدة البيانات واختبار الأمان والخصوصية وشروط الاستخدام.

## طريقة التجربة من موبايل أندرويد فقط (بناء سحابي)
يمكنك طلب بناء APK من GitHub Actions دون تثبيت Android Studio على الهاتف، لكن يلزم حساب GitHub ورفع ملفات المشروع إليه. هذه الطريقة تبني نسخة تجريبية (Debug APK) وليست نسخة جاهزة للنشر على Google Play.

1. فك ضغط الملف على الهاتف باستخدام مدير الملفات.
2. افتح GitHub في المتصفح وأنشئ مستودعًا جديدًا باسم `wesla-android`، واجعله خاصًا إن كنت تفضّل ذلك.
3. ارفع **محتويات** مجلد `wesla_android` إلى المستودع مع الحفاظ على المجلد المخفي `.github/workflows/build-android.yml`. قد تحتاج إلى تفعيل عرض الملفات المخفية أو رفع المجلد من تطبيق/متصفح يدعمها.
4. من صفحة المستودع افتح تبويب **Actions**، واختر **Build Wesla Android APK**، ثم **Run workflow**.
5. بعد نجاح التشغيل، افتح نتيجة التشغيل وابحث عن **Artifacts** ثم نزّل `wesla-debug-apk`.
6. فك ضغط ملف الـArtifact، ثم افتح `app-debug.apk` على هاتفك ووافق على التثبيت من هذا المصدر إذا طلب أندرويد ذلك. لا تثبّت APK من مصدر لا تثق به.

إذا لم يظهر الـworkflow، فتأكد أن الملف موجود في المسار `.github/workflows/build-android.yml` داخل المستودع. وقد تتغير أسماء الأزرار قليلًا بحسب واجهة GitHub.
